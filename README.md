# PaneLift

Any window from your Mac, on your iPhone and iPad.

This repository holds PaneLift's website, served at
**https://wongfei2009.github.io/panelift-site**, and PaneLift for Mac's
[releases](https://github.com/wongfei2009/panelift-site/releases).

- **Download PaneLift for Mac** (free): https://wongfei2009.github.io/panelift-site/download
- **Support:** https://wongfei2009.github.io/panelift-site/support, or [open an issue](https://github.com/wongfei2009/panelift-site/issues/new/choose).
- **Privacy policy:** https://wongfei2009.github.io/panelift-site/privacy
